Troubleshooting Guide

❌ "Authentication failed"

Your credentials are wrong or the switch rejected the login.

Solutions:
  • Verify credentials: Username=networks, Password=w00Lw0rTh$
  • Test SSH manually: ssh networks@192.168.101.212
  • Check if SSH is enabled on the switch
  • Verify the .env file has correct credentials

❌ "Connection timeout" / "not reachable"

The switch IP address is not accessible from the container.

Solutions:
  • Verify switch IP is correct (192.168.101.212 or 192.168.101.101)
  • Ensure switch is powered ON and has network connectivity
  • Test network connectivity from your host: ping 192.168.101.212
  • Check firewall rules allow SSH (port 22) to the switch
  • Verify Docker container network settings
